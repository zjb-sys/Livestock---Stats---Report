# 畜牧业数据管理系统

乌兰木伦镇养殖户数据管理平台。单文件纯前端应用，无需后端服务，浏览器打开即可使用，数据存储于浏览器本地（localStorage）。

## 功能模块

### 1. 参数调整
- 动物出栏体重：猪、牛、山羊、绵羊、鸡的出栏体重（kg）
- 出肉率：各类肉类出肉率（%）
- 蛋鸡产蛋参数：年产蛋数、单颗蛋重量
- 奶牛产奶参数：产奶天数、日产量

参数修改后点击“保存参数”持久化；点击“应用到计算”使后续录入生效；历史数据产量需手动点击“重新计算所有数据”更新。

### 2. 数据录入
分四步填报：
1. 基础信息：填报单位、养殖户姓名、填报日期
2. 存栏数据：猪、牛、羊、禽的存栏数量
3. 出栏数据：各类动物出栏数量、全年产蛋鸡数量、全年奶牛数量
4. 主要产品产量：猪肉、牛肉、羊肉（山羊肉+绵羊肉）、鸡肉、鸡蛋、生牛奶（吨）

支持“自动计算产量”：根据出栏/产蛋/产奶数据及已保存参数自动算出各产品产量，覆盖空白字段。同一填报单位下同名养殖户视为重复记录，保存时会提示覆盖。

### 3. 数据汇总与展示
- 汇总卡片：总存栏量、总出栏量、总产量、养殖户数量
- 明细表格：所有养殖户记录列表，支持按养殖户姓名或填报单位筛选
- 操作：编辑、删除记录；导出 CSV；生成 HTML 报告；刷新汇总；数据校验；重新计算所有数据

## 业务校验规则

- 能繁母猪 ≤ 猪存栏
- 肉牛 + 奶牛 ≤ 牛存栏
- 肉鸡 + 蛋鸡 ≤ 活鸡存栏
- 各类动物出栏 ≤ 对应存栏
- 填报日期不能晚于今天
- 产量异常时会弹窗确认是否继续保存

## 数据导出

- **导出数据**：将所有记录导出为 UTF-8 BOM 编码的 CSV 文件，可直接用 Excel 打开
- **生成报告**：将筛选后的汇总与明细导出为 HTML 文件，可打印或在浏览器查看
- **导入数据（CSV）**：支持将导出的 CSV 重新导入，与导出形成闭环（Excel 可另存为 CSV 后导入）

## 使用方法

1. 直接用浏览器打开 `A_412.html`
2. 在“参数调整”中设置或确认计算参数，点击“保存参数”
3. 切换到“数据录入”，填写养殖户数据，点击“保存”
4. 切换到“数据汇总”，查看汇总卡片和明细表格
5. 如需备份数据，点击“导出数据”保存 CSV；如需打印报表，点击“生成报告”

## 数据存储与安全

- 数据仅保存在浏览器本地 `localStorage` 中，不上传任何服务器
- 清除浏览器缓存或更换浏览器/设备会导致数据丢失，请定期导出 CSV 备份
- 页面关闭时如录入表单有未保存更改，会弹出确认提示

## 开发说明

本项目为单文件静态页面，无构建工具、无框架、无依赖，适合内网或离线环境部署。如需扩展，建议按模块（参数、录入、汇总、存储、导出）拆分为多个文件并引入构建工具。
